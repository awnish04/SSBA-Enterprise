# SSBA Enterprise – Promotional Website

A single-page promotional website for **SSBA Enterprise**, an IT company based in Biratnagar, Nepal.
Live at: <https://ssba-enterprise.vercel.app/>

## Tech Stack

- **Next.js 15** (App Router)
- **TypeScript**
- **Tailwind CSS v4**
- **Framer Motion** – section animations
- **Embla Carousel** – services carousel
- **Lucide React** – service icons

---

## Running Locally

```bash
# 1. Install dependencies
npm install

# 2. Start the development server
npm run dev
```

Open <http://localhost:3000> in your browser.

```bash
# Build for production
npm run build

# Preview the production build
npm run start
```

## Submitting / Zipping

**Include:**
- `src/`
- `public/`
- `package.json`
- `package-lock.json`
- `next.config.ts`
- `tsconfig.json`
- `components.json`
- `README.md`

**Exclude (do not zip):**
- `node_modules/` — regenerated by `npm install`
- `.next/` — build output, regenerated by `npm run build`
- `.git/` — version control history
- Any `.env` or `.env.local` files
